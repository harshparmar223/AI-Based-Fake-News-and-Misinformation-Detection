Technical Defense FAQ for Faculty Review

Q1: Why did Linear Support Vector Machines outperform Random Forests?

In high-dimensional sparse vector spaces (10,000 TF-IDF features), document representations are largely linearly separable across hyperplane boundaries. Linear SVM finds the maximum margin hyperplane without greedily splitting axes like axis-aligned decision trees. We applied 3-fold Platt calibration (CalibratedClassifierCV) to generate well-calibrated class probabilities for confidence estimation and LIME.

Q2: How does LIME feature attribution work under the hood?

LIME (Local Interpretable Model-agnostic Explanations) draws perturbed samples by randomly masking individual words from the target article, runs these variations through the multi-model ensemble's predict_proba function, weights them by exponential cosine distance to the original document, and fits an interpretable ridge regression surrogate model whose coefficients represent the exact signed contribution of each token.
